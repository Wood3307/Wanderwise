# 平行宇宙与虫洞联想

三个知识纵深的左下入口连接到平行宇宙。每次围绕当前搜索主题生成 12 个相关方向，每个方向由一个虫洞承载；没有搜索词时使用当前热点问题。关键词是继续检索的方向，不是虚构的知乎文章。

## 操作

- 鼠标拖动旋转视角，滚轮向外缩小显示尺度、向内靠近；悬停话题或虫洞并继续向内滚动可进入该方向。
- 点击关键词或虫洞，会以缩放过渡接近并进入。键盘焦点与 Enter 同样可用。
- 手机使用单指拖动和双指缩放。取消手势与向外缩放不会误触穿越。
- 原话题虫洞可返回进入前的星海，Esc 也可取消或返回。
- 穿越后继续沿用问题星系、回答恒星、文章段落三层逻辑，并可再次进入平行宇宙。

超立方体、墙面坍缩、自动鼠标转向和 W/A/S/D 飞行控制已移除。所有方向的穿越统一使用居中的蓝白光纤隧道。

## 画面

虫洞分为光晕、虹彩漏斗、金色旋涡、青色涡流与珊瑚色焰环五种造型，使用稳定三维分布。关键词保持水平仿宋，和虫洞共享世界坐标投影并避让，保持可读性。空间不显示常驻标题、口号、操作说明或坐标列表。

背景使用官方创世之柱影像，以 CSS 压暗和裁切作为远景；底部按发布方要求保留完整、可见的来源署名。[背景素材说明](galaxy-parallel-background.md)。

## 数据与失败处理

`POST /api/associations` 接受 `query`、最多 12 条上下文标题和最多 32 个近期方向。响应为 `{seed, topics: [{id, keyword, relation}], method, notice?}`。默认通过跨领域语义关系和当前上下文生成方向；已有显式模型配置时支持模型拓展，并在模型不可用时降级。

主应用复用 `MODEL_*` 或 `ZHIHU_MODEL_ENABLED` 配置。联合应用遵循最新版宿主的直接访客访问、官方 CLI 与共享 AI 预算；模型不可用或额度不足时仍可使用语义拓展。Access Secret 不进入浏览器。不会提前为所有方向批量请求知乎。

选择方向后仅调用一次已有 `/api/explore?q=...`，并把同一结果交给星空应用。等待时停留在光隧道，成功后显现新星海；空结果和请求失败回到联想空间，原查询与原内容保留。取消、组件卸载及结束旅行都会使旧请求失效。新旅行清空近期方向；在同一旅行内穿越不会清空足迹。

## 渲染与资源

每个平行虫洞使用一片着色平面，12 个方向和返回入口合计 13 个模型，加上有界星点。复用原星图的立体分布和文字避让，按帧耗时调整分辨率。进入等待期间先渲染目标场景；真实首帧完成后才能揭幕，避免旧星海闪回。

蓝白隧道使用一片全屏三角形、缓存噪声和有上限的绘制分辨率，进出使用相同着色器和时长。离开时释放场景、上下文、纹理和事件监听；保留原星海相机记忆、单次旅行与收藏。减少动态效果仍可手动探索。

## 验证入口

```sh
npm test
npm run build
npx playwright test tests/wormhole.spec.ts
```

浏览器测试用隔离内容覆盖三层往返、鼠标拖动与投影、取消旧飞行键、连续滚轮目标锁定、再次联想、返回、失败/取消、双向蓝白隧道首帧握手、手机拖动/双指缩放和结束旅行中止请求。联合应用使用同一测试，设置 `WORMHOLE_ENTRY_PATH=/galaxy` 与 `PLAYWRIGHT_BASE_URL`。测试不会批量消耗真实搜索额度。
